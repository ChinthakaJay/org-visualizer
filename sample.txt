# sample.txt: a fictional company, showing what Org Visualizer can draw.
# Run it with:  npm start -- sample.txt
#
# One fact per line, in any order. Lines starting with # are comments.
#   Teams:   team <id> : <Title> | parent=<team-id> | color=<name or #hex>
#   People:  <id> : <Name> | team=<team-id> | reports=<person-id or ?> | role=… | fn=… | dotted=<id>,…
#   Any other key=value on a Person (met=, location=, …) is kept as a detail and shown on hover.
